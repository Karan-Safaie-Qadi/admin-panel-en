# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2025-06-22

### Added
- Initial release of Digital Store Admin Panel
- Dashboard with statistics cards, charts (line, doughnut, bar), and order flow
- Product management with full CRUD operations
- Category management with CRUD support
- Order management with status filtering
- User management with activation toggle
- Reports page with sales and revenue charts
- Dark blue theme with yellow accents (RTL support)
- Responsive design for mobile and desktop
- SPA architecture with hash-based routing
- Data loading from JSON test file
